One workspace from detection to review

Mustatil 6 combines large-raster inference, satellite imagery workflows, video analysis, annotation, training, segmentation, and GIS-ready export.

Mustatil is built for projects where conventional computer-vision tools become impractical: huge GeoTIFF and BigTIFF files, satellite mosaics, remote-sensing imagery, archaeology, geospatial surveys, and long-running tiled detection jobs. The workspace keeps model selection, inference, annotation, quality review, and export together in one desktop interface.

Mustatil means rectangle — a reference to both archaeological mustatils and the rectangular detection boxes used in AI object detection.

Mustatil 6 features

A broader workspace for geospatial AI, image intelligence, dataset preparation, model development, and operational review.

  • Object detection in huge GeoTIFF and BigTIFF datasets
  • Memory-conscious tiled processing with overlap control
  • Satellite imagery detection and remote-sensing workflows
  • YOLO, Faster R-CNN, RF-DETR, Mask R-CNN, U-Net and DINO support
  • Video detection, annotation, timeline review, and export
  • SAM2-assisted segmentation from boxes and annotations
  • Integrated annotation, class management, and dataset creation
  • Graphical AI pipeline workflows and model chaining
  • Detection filtering, scoring, and FormTrainer integration
  • Exports to GeoJSON, GeoPackage, CSV, images, masks, and datasets

AI model support

Use fast detectors, proposal-based networks, transformer architectures, semantic segmentation, interactive masks, and prompt-driven workflows.

YOLO / Ultralytics

Tiled detection, training, class filtering, review, model comparison, and GIS export for Ultralytics-compatible models.

Faster R-CNN

Proposal-based detection with selectable backbones and large-image tiled inference.

RF-DETR

Modern transformer-based object detection as an alternative to conventional one-stage detectors.

Mask R-CNN

Instance segmentation for projects that require object masks in addition to bounding boxes.

U-Net

Pixel-level semantic segmentation for remote sensing, raster classification, and image-to-mask workflows.

SAM2

AI-assisted segmentation using annotation boxes as prompts, with single-image and batch processing.

Grounding DINO

Text-guided detection and flexible prompt-based localization beyond fixed training classes.

OWL-ViT / OWLv2

Experimental open-vocabulary detection for locating concepts from text prompts.

LAE-DINO and advanced workflows

Project-based training, detection, experimentation, filtering, and model-assisted review.
