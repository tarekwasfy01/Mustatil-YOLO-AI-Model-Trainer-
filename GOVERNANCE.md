# Governance

Mustatil is currently a single-maintainer open-source project led by Tarek Wasfy.

The maintainer is responsible for release decisions, architecture, licensing, moderation, and acceptance of contributions. Design proposals are discussed in public GitHub issues whenever they do not involve security or sensitive location data. Contributions are evaluated for correctness, maintainability, compatibility with the local-first research workflow, and licensing.

If the contributor community grows, maintainers may be added based on sustained, constructive contributions. Changes to governance will be documented in this file.
