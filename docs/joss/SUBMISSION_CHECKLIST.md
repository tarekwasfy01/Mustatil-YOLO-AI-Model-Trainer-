# JOSS submission checklist

## Repository

- [ ] Complete source is directly browsable as normal files
- [ ] Repository has been public for more than six months
- [ ] Development activity spans that period
- [ ] OSI-approved `LICENSE` file is present
- [ ] Clean clone installs without private files
- [ ] Tests exercise research-critical functionality
- [ ] CI passes on supported platforms
- [ ] Documentation includes installation, quick start, and examples
- [ ] `CONTRIBUTING.md`, support, and governance expectations are public
- [ ] Tagged release and changelog are current
- [ ] Exact submitted release is archived with a DOI

## Paper

- [ ] 750–1750 words excluding metadata and references
- [ ] Required JOSS sections are present
- [ ] State of the field cites related software
- [ ] Build-versus-contribute rationale is explicit
- [ ] Research impact is specific and not merely aspirational
- [ ] Paper does not present new research results
- [ ] AI use is disclosed with tools, scope, and verification
- [ ] All citation keys compile from `paper.bib`
- [ ] PDF builds with the Open Journals action

## Submission

- [ ] Repository URL and release tag identify the exact version
- [ ] Archive DOI resolves to that release
- [ ] Author and affiliation metadata are accurate
- [ ] Conflict-of-interest information is accurate
- [ ] Author is prepared to answer reviewers personally in the public review issue
